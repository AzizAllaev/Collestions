## Collections
Данное решение содержит проекты которые демострируют как работать
с коллекциями в C#. В данном решении рассмотрены следующие коллекции:
- `List<T>` - список, который содержит элементы, которые могут повторяться
- `Dictinary<TKey, TValue>` - список, который содержит пары ключ-значение
- `LinkedList<T>` - множество, которое содержит элемнты хранят ссылки друг на друга
- `Queue<T>` - очередь, которая работает по принципу FIFO
- `Stack<T>` - стек, который работает по принципу LIFO
